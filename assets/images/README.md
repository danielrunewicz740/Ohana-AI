# Assets — Images

Place dog profile photos in this directory.

Naming convention: `{dog_id}_{dog_name_lowercase}.png`

Examples:
- `1_anubis.png`
- `2_rex.png`
- `3_buddies.png`
- `4_luna.png`
- `5_mochi.png`
- `6_daisy.png`

When an image asset is missing, the `DogProfileCard` widget falls back to
a circular avatar showing the dog's initial letter.
